## 五轴抽卡

五轴固定为风格、主体、构图、色彩和动态。卡池只读取用户关键词库，支持锁定、单轴重抽、全部重抽和送入托盘。

空关键词库不会填入演示卡。请从网页划词、图片解构或手动创建开始。

## 提示词顺序

最终提示词按五轴稳定顺序拼接，再追加词卡托盘和正文。托盘按关键词 ID 去重。

## 参考关系

- 正文与主体优先级最高。
- 角色脸只发送用户确认的裁切图。
- 姿态只约束动作、位置、透视和受力。
- 每个批次只启用一张色卡，并整批生效。

Provider 不支持某项能力时，预检会禁用该引用，不会假装已经应用。

## 批次与卡池

每批支持 1–10 张，并发 1–4。父批次和子任务在请求前写入本地数据库。部分失败时成功结果仍可揭示、保存和下载；“补全失败位置”只重试失败索引。
