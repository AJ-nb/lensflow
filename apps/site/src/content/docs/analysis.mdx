## 第一核心能力

Lensflow 的基础能力是“分析产品并给出可编辑提示词”。它优先识别实体产品和器物；人物、场景、平面内容或无法确认的输入会退化为通用视觉分析，不会硬套产品字段。

快速分析固定为一次视觉 Structured Output 请求，输出：

- 内容分类、产品或主体摘要、形态结构与 CMF。
- 构图、镜头、光线、风格和可见文字。
- 中英文正向/负向提示词。
- 忠实复现、商业呈现、概念变化三种变体。
- 风格、主体、构图、色彩、动态五轴建议。

“深入分析”只能由用户主动触发。它提高结构、设计智能和 CMF 的细节密度，最多增加三次分析请求；不会自动重试失败请求。

## 证据等级

| 等级 | 含义 |
|---|---|
| `measured` | 浏览器在本机从像素或文件读取的尺寸、比例、方向和十六进制色卡。 |
| `observed` | 模型能直接从画面指出的可见事实。 |
| `inferred` | 基于画面的解释，例如可能的材质或设计意图。 |
| `unknown` | 证据不足，不能可靠确认。 |

模型不能输出或覆盖 `measured` 值。Schema 部分失败时，Lensflow 保留原图、有效字段和原始响应，在本机把任务标记为 `partial`。

## 提示词版本

编辑后的提示词以新版本追加，不覆盖分析结果。每个版本保存来源素材、来源分析、语言、变体类型和分析模型，可复制、收藏到提示词册或送入 Composer。

## 状态与中断

分析状态为 `queued`、`preparing`、`analyzing`、`ready`、`partial`、`failed` 或 `interrupted`。中断、超时、429 与服务端错误不会触发自动付费重试。
