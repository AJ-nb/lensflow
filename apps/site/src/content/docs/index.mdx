Lensflow 是一个无账号、无积分、无云数据库的 Chrome 本地 AI 创作工作台。

## 工作流

1. 在网页图片上使用 `P` 反推提示词，或使用 `V` 反推后进入生成。
2. 先读取本地测量结果，再查看 Provider 返回的语义解构。
3. 使用风格、主体、构图、色彩、动态五轴组合提示词。
4. 在预检中确认模型、画幅、数量、清晰度和参考关系。
5. 生成结果自动进入历史，主动保存后才进入作品集。

## 数据位置

- API Key 默认只存在于 `chrome.storage.session`。
- 捕捉、分析、提示词、参考、任务、资产和历史保存在插件 IndexedDB。
- 网站 Studio 只通过 v1 受限桥接访问本机插件。
- 备份和诊断包永不包含 API Key。

Lensflow 不包含内置图片、模板或预置关键词。首次使用从自己的网页图片、本地图片或关键词开始。
