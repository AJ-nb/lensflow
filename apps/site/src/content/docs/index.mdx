Lensflow 是一个无账号、无积分、无云数据库的 Chrome 本地 AI 创作工作台。

## 工作流

1. 在网页图片上使用 `P` 完成分析，或使用 `V` 分析后预填创作。
2. 先读取本地测量，再用一次结构化视觉请求得到产品/通用分析、证据边界和双语提示词。
3. 编辑或收藏提示词版本，再使用风格、主体、构图、色彩、动态五轴组合。
4. 在预检中确认模型、画幅、数量、清晰度、色卡和参考关系。
5. 生成结果自动进入历史，主动保存后才进入作品集；成功项可以批量下载或导出 Eagle。

## 数据位置

- API Key 默认只存在于 `chrome.storage.session`。
- 捕捉、分析、提示词、参考、任务、资产和历史保存在插件 IndexedDB。
- 网站 Studio 只通过 v2 受限桥接访问本机插件；原始 Provider 响应不会经过桥接。
- 备份和诊断包永不包含 API Key。

Lensflow 不包含内置图片、模板或预置关键词。首次使用从自己的网页图片、本地图片或关键词开始。
