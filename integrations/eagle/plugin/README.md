# Lensflow · Eagle 工作台

Eagle 4 窗口插件，用于第四阶段 A 的全库标签映射预览和批处理队列。

## 安装

1. Eagle 菜单选择“插件中心 → 开发者选项 → 导入本地项目”。
2. 选择本目录 `integrations/eagle/plugin`。
3. 从插件菜单打开“Lensflow · Eagle 工作台”。

## 写入策略

- 自动写入仅依据现有文件夹名称、通用阶段词和文件扩展名；文件夹被映射为 `图库/*`，不预设产品领域。
- 始终保留已有标签，只追加新标签。
- 材料、工艺、结构零件、AI 来源、产品同款和真实来源不会自动写入。
- 队列开始前会生成内存基线，可点击“导出基线”保存 JSON。
- 每项写入后使用 `eagle.item.getById()` 回读核验。
- 可暂停、继续并重试失败项，结束后可导出结果 JSON。

本插件不包含去除背景功能，也不修改图片文件。
