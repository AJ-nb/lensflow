# Lensflow v0.3.0

这是一次新手体验、更新协议和项目证据回补版本。它不增加账号、积分、收费、云同步或新的 Provider 兼容性声明。

## 新增

- Studio 五步新手引导：按真实素材、分析、组合、预检和结果事件记录进度，支持跳过、关闭、刷新续接及从帮助按钮恢复。
- `/studio?demo=1` 原创离线示例：使用预计算分析与五轴词卡，不连接插件、不读取密钥、不调用 Provider，也不写入用户资产。
- Release Manifest v2：记录数据版本、最低 Chrome、桥接版本、迁移要求，以及每个分发包的渠道、大小和 SHA-256。
- stable 与 beta 独立更新清单；GitHub ZIP 安装每 24 小时至多检查一次，只提醒并打开手动更新页。
- Viko 公开页面证据拆解、Lensflow PRD、创作空间、新手引导、架构、发布迁移与四套原创 UI 探索图进入仓库。

## 优化

- 首页区分未安装、当前版本、可更新、协议不兼容、清单离线和桥接阻断，并忽略 stable 路径上的 beta 清单。
- 高级设计工具与 Eagle 桥改为按需加载；侧边栏展示组件拆分为独立模块，数据合同与已有行为不变。
- 保持 1024 px 两栏工作台；移动网页继续是只读结果查看与下载，不开放完整编辑。

## 升级

1. 在旧版本设置中导出本地备份。
2. 下载 `lensflow-v0.3.0-chrome.zip`，并使用 `SHA256SUMS.txt` 校验文件。
3. 解压到固定目录，在 `chrome://extensions` 中覆盖原目录并点击“重新加载”。
4. 打开 Studio，检查资产、提示词、参考、批次与历史；API Key 不属于备份内容。

本版本数据版本为 2，最低兼容数据版本为 1；没有强制迁移，但覆盖安装前仍建议备份。GitHub ZIP 受 Chrome 安全模型限制，不会静默下载或自动安装更新。Chrome Web Store 自动更新仅在正式商店版本发布后适用。

## 已知限制

- 彼源、OpenAI-compatible 与 ComfyUI 适配器通过模拟合同测试；未经授权的真实 Provider 烟测前，兼容性仍为 `UNKNOWN`。
- Viko 登录后的私有 Studio 与服务端实现未验证，也不属于 Lensflow 的复制范围。
- 完整移动端编辑、账号、收费、云同步、团队协作和公共作品社区仍为 `DEFERRED`。
- OCR、主体分区、SVG、Eagle 与 ComfyUI 属于高级工具，其真实外部环境兼容性需分别验证。

## 构建来源

Release ZIP 由标签对应的 GitHub Actions 工作流构建并附 GitHub artifact attestation。可运行 `gh attestation verify lensflow-v0.3.0-chrome.zip --repo AJ-nb/lensflow` 验证来源。
