# Lensflow v0.3.2

这是 Provider 绑定流程与窄屏交互的补丁版本。它不增加账号、积分、收费、云同步，也不扩大任何未经真实烟测的 Provider 兼容性声明。

## 绑定流程

- 首屏只保留 Provider 预设、API Key 和一个与当前状态对应的主操作，减少首次配置时的选择负担。
- 连接成功后才要求确认分析模型与图像模型；Base URL、协议、密钥管理、手动模型和能力检测收纳到“高级设置”。
- 切换彼源或 OpenAI-compatible 等远程 Provider 时不会沿用上一 Provider 的密钥，避免把旧凭据发送到新地址。
- 只有模型目录提供明确用途信息时才自动选择模型；信息含糊时必须由用户确认。
- 能力检测继续是可选操作，执行前明确提示可能产生请求或费用，不会自动运行或自动重试。

## 状态与交互修复

- 连接失败与激活失败使用不同恢复路径；活动配置失效时显示“重新启用”，不会误导用户重新执行连接测试。
- 重复点击当前 Provider 预设不再重置未保存的 URL、协议、模型或密钥操作。
- 保留候选测试、草稿密钥与活动密钥隔离，以及激活失败回滚；测试失败不会修改当前活动配置。
- Provider 响应中的模型用途现在经过规范化判断，避免仅凭模型名称猜测并静默选错分析或图像模型。
- 360 px 侧边栏中的失败操作区可稳定换行，不产生横向溢出，底部主操作保持可见。

## 安装与升级

1. 在旧版本设置中导出本地备份。
2. 下载 `lensflow-v0.3.2-chrome.zip` 和 `SHA256SUMS.txt`。
3. 校验 ZIP 的 SHA-256 后解压到固定目录。
4. 在 `chrome://extensions` 中覆盖旧目录并点击“重新加载”。
5. 打开 Studio，确认原有资产、历史与活动 Provider 状态。

本版本继续使用数据版本 3，不执行新的数据库迁移。GitHub ZIP 仍需手动安装和更新，浏览器安全模型不允许 Lensflow 静默替换插件。

## 验证与边界

- 发布候选本地验证：40 个测试文件、176 个单元测试、27 个端到端场景、类型检查、网站与扩展生产构建全部通过。
- 本次没有使用真实 API Key，也没有向真实 Provider 发送请求。
- 彼源、OpenAI-compatible 与 ComfyUI 适配器通过模拟合同测试；未经用户授权的真实 Provider 烟测前，兼容性仍为 `UNKNOWN`。
- 付费分析、图像生成与能力检测不会自动重试。

Release ZIP 由标签对应的 GitHub Actions 工作流构建并附 GitHub artifact attestation。可运行 `gh attestation verify lensflow-v0.3.2-chrome.zip --repo AJ-nb/lensflow` 验证来源。
