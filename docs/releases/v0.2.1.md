# Lensflow v0.2.1

这是面向现有 `v0.2.0` 用户的兼容性与安全边界热修复，不增加新的 Provider 能力。

## 修复

- 网站安装检测与扩展统一使用桥接协议 v2，避免已安装当前版本时误报更新。
- 协议不兼容时先读取稳定版发布清单；没有更高版本时不再显示“更新到当前版本”。
- 移动网页 Runtime 集中拒绝所有桥接写方法，结果区同时隐藏重试、取消、收藏和 Eagle 导出。
- 移动结果区保留揭示与下载，并使用稳定的两列操作布局。
- 固定 Node.js `24.14.1` 与 npm `11.11.0`，统一本地、CI 和发布工具链。

## 升级

1. 在旧版本中先打开“本地备份与恢复”并导出备份。
2. 下载 `lensflow-v0.2.1-chrome.zip`，校验 Release 附带的 SHA-256。
3. 解压到固定目录，在 `chrome://extensions` 中覆盖原目录并点击“重新加载”。
4. 打开 Lensflow Studio，确认资产、提示词、参考和历史仍可读取。

## 已知限制

- GitHub ZIP 版本受 Chrome 安全模型限制，只提供更新提醒和手动升级说明，不会静默自动更新。
- 彼源、OpenAI-compatible 与 ComfyUI 适配器通过模拟合同测试；真实兼容性必须由用户授权的 Provider 烟测确认。
- Viko 登录后的私有 Studio 与服务端实现未验证，也不属于 Lensflow 复制范围。

## 构建来源

Release ZIP 由标签对应的 GitHub Actions 工作流构建，并附 GitHub artifact attestation。可使用 `gh attestation verify lensflow-v0.2.1-chrome.zip --repo AJ-nb/lensflow` 验证来源。
