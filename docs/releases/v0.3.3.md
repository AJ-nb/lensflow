# Lensflow v0.3.3

这是 Provider 认证失败恢复流程的补丁版本。它修复已保存凭据被 Provider 拒绝后仍重复测试同一凭据的问题，不增加账号、积分、收费、云同步，也不扩大任何未经真实烟测的 Provider 兼容性声明。

## 认证恢复

- Provider 返回 `401 authentication` 后，主操作会明确变为“替换 API Key”，不再使用已被拒绝的保存凭据重新测试。
- 点击恢复操作会展开快速连接区的 API Key 输入框并自动聚焦，减少在高级设置中寻找入口的步骤。
- 新密钥为空时连接操作保持禁用，避免再次提交无效候选配置。
- 凭据恢复入口使用专用密钥图标，并保留候选配置、草稿密钥与活动密钥的隔离边界。

HTTP `401` 只证明 Provider 拒绝了本次凭据，不能单独证明凭据是输错、过期、撤销，还是目标接口配置不匹配。Lensflow 不会在错误详情、导出或诊断中包含 API Key 明文；凭据只按用户选择保存在当前会话或浏览器本机。系统也不会自动重试可能计费的分析、生成或能力检测请求。

## 安装与升级

1. 在旧版本设置中导出本地备份。
2. 下载 `lensflow-v0.3.3-chrome.zip` 和 `SHA256SUMS.txt`。
3. 校验 ZIP 的 SHA-256 后解压到固定目录。
4. 在 `chrome://extensions` 中覆盖旧目录并点击“重新加载”。
5. 打开 Studio，确认原有资产、历史与活动 Provider 状态。

本版本继续使用数据版本 3，不执行新的数据库迁移。GitHub ZIP 仍需手动安装和更新，浏览器安全模型不允许 Lensflow 静默替换插件。

## 验证与边界

- 发布候选本地验证：40 个测试文件、178 个单元测试、27 个端到端场景、类型检查、网站与扩展生产构建全部通过。
- 本次没有使用真实 API Key，也没有向真实 Provider 发送请求。
- 彼源、OpenAI-compatible 与 ComfyUI 适配器通过模拟合同测试；未经用户授权的真实 Provider 烟测前，兼容性仍为 `UNKNOWN`。
- 修复验证覆盖 `401` 恢复入口、自动聚焦、空密钥禁用和 360 px 窄屏无横向溢出。

Release ZIP 由标签对应的 GitHub Actions 工作流构建并附 GitHub artifact attestation。可运行 `gh attestation verify lensflow-v0.3.3-chrome.zip --repo AJ-nb/lensflow` 验证来源。
