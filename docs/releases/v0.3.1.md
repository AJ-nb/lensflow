# Lensflow v0.3.1

这是 Provider 配置事务、分析错误安全和关键交互的补丁版本。它不增加账号、积分、收费、云同步，也不扩大任何未经真实烟测的 Provider 兼容性声明。

## 修复

- Provider 测试不再提前覆盖当前活动配置或密钥；失败候选只能由用户明确保存为未激活草稿。
- API Key 改为“保留、替换、清除”三态，空输入不再代表删除；激活会先重新验证模型目录，再原子切换活动配置。
- 401、403、404、429、5xx、网络、超时、无效响应和取消现在使用结构化错误与不同修复建议。
- 彼源返回 502 HTML 时，Studio 不再展示整页 Cloudflare 源码，也不会错误暗示 API Key 无效。
- 网页桥接、备份与诊断导出不再包含技术详情、完整 Provider 响应正文或密钥字段。

## 交互与可访问性

- Provider 对话框显示当前活动配置、未激活草稿和密钥保存位置，并支持失败后重新测试或保存草稿。
- 分析错误回到分析步骤内展示；技术详情默认折叠、限制高度并强制换行。
- 侧边栏使用稳定按钮布局和视口内抽屉；360 px 宽度下核心操作保持可见。
- 错误面板加入 `role="alert"`、焦点定位、复制诊断和关闭后焦点恢复。

## 数据迁移

本版本将本地数据库升级至数据版本 3。首次打开会自动清理旧分析、生成任务和历史事件中的 HTML 或超长错误，并将可识别的 401、429、502 等旧错误转换为结构化失败；素材、结果和失败记录都会保留。

升级前仍建议在设置中导出本地备份。API Key 从不属于备份内容。

## 安装与升级

1. 下载 `lensflow-v0.3.1-chrome.zip` 和 `SHA256SUMS.txt`。
2. 校验 ZIP 的 SHA-256 后解压到固定目录。
3. 在 `chrome://extensions` 中覆盖旧目录并点击“重新加载”。
4. 打开 Studio，检查数据迁移结果和 Provider 状态；旧活动密钥不会在界面中显示。

GitHub ZIP 仍需手动安装和更新，浏览器安全模型不允许 Lensflow 静默替换插件。

## 验证与边界

- 发布前本地验证：39 个测试文件、155 个单元测试、27 个端到端场景、类型检查、网站与扩展生产构建全部通过。
- 彼源、OpenAI-compatible 与 ComfyUI 适配器通过模拟合同测试；未经用户授权的真实 Provider 烟测前，兼容性仍为 `UNKNOWN`。
- 本版本没有执行可能计费的自动重试；能力检测仍需用户明确确认。

Release ZIP 由标签对应的 GitHub Actions 工作流构建并附 GitHub artifact attestation。可运行 `gh attestation verify lensflow-v0.3.1-chrome.zip --repo AJ-nb/lensflow` 验证来源。
